SRI METHOD C — Logic Engine
sri_method_c_FINAL.py
================================================================================

REQUIREMENTS
------------
Python 3.10+

    pip install pandas numpy

Standard library modules used: json, os, datetime, fractions, math.


DATA NEEDED
-----------
Download from OneDrive and place locally:

  SRI Calculator/Method C/Data 2026 - 180dd/    <- 50 CSV files (Home Assistant)
  SRI Calculator/Method C/IFC/                  <- 3 IFC model files


PATH CONFIGURATION
------------------
Open sri_method_c_FINAL.py and update the three variables at the top
of the file (search for "PATH CONFIGURATION"):

    _BASE      = r"C:\...\WORKING DOCS"           <- root of your local copy
    CSV_DIR    = _BASE + r"\SRI Calculator\Method C\Data 2026 - 180dd"
    IFC_DIR    = _BASE + r"\SRI Calculator\Method C\IFC"
    OUTPUT_DIR = r"C:\...\Python"                 <- where outputs will be saved

On macOS/Linux use forward slashes.


RUN
---
    python sri_method_c_FINAL.py


OUTPUT
------
Two files saved to OUTPUT_DIR (timestamped YYYYMMDD_HHMM):

    sri_method_c_YYYYMMDD_HHMM.json    <- structured results (source of truth)
    sri_method_c_YYYYMMDD_HHMM.html    <- visual dashboard (open in browser)


UPDATING THE DATASET
--------------------
To extend the analysis period (e.g. January-September 2026):
replace the CSV files in the data folder with the updated exports
(same filenames). The analysis period is detected automatically
from the timestamps. No code changes required.


* CSV FORMAT NOTE
-----------------
The script expects CSV files exported from Home Assistant organized by
building area, using the specific filenames generated by the Villa Segrate
Home Assistant configuration. Each file must contain the columns:
entity_id, last_changed, state.

Exports organized by device or entity rather than by area will use
different filenames and will not be recognized by the service check
functions. Adapting the script to a different export structure requires
updating the filename references inside each check function.
